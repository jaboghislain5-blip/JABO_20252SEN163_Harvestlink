## 1. Project Overview

HarvestLink Rwanda is a proposed Oracle database system designed to support agricultural cooperatives in recording received produce, monitoring stock movements, reconciling recorded inventory with physical stock, and documenting post-harvest losses.

The project will also include an analytics dashboard developed using Power BI and connected to Oracle Database.

## 2. Problem Statement

Agricultural cooperatives need reliable ways to manage produce records, monitor inventory movements, record post-harvest losses, and identify differences between recorded and physically available stock.

HarvestLink Rwanda proposes a centralized database solution to support these activities and improve inventory reporting.

These challenges are initial working assumptions that will be refined through research and stakeholder consultation.

## 3. Main Objective

To develop an Oracle database system that supports cooperative inventory management, stock reconciliation, and post-harvest loss monitoring.

## 4. Specific Objectives

- Record produce received by cooperatives.
- Monitor inventory and stock movements.
- Record post-harvest losses and their causes.
- Compare recorded stock with physical stock counts.
- Generate inventory and loss reports.
- Present key indicators through a Power BI dashboard.
